# 地方旗アトラス UI仕様

承認済みコンセプトは `../design/nationwide-map-concept.png`。実装アーキテクチャは
`../docs/architecture/rendering.md`を参照する。

- 真っ白なヘッダーと詳細ドロワー、地図面は淡い寒色グレー。
- 文字は日本語サンセリフ、本文 `#202326`、補助情報 `#626970`。
- 罫線 `#ccd2d7`、未照合 `#edf0f2`、選択色 `#d3261d`。
- ヘッダー高64px、検索幅400px、詳細ドロワー幅356px。
- 角丸は4〜8pxに抑え、カードの多用や装飾的な影は避ける。
- 地図を主役とし、常設要素は検索、凡例、ズーム操作のみ。
- 選択時だけ右ドロワーを開き、モバイルでは下部シートにする。
- アイコンは24px以下、2px線のコードネイティブSVGで統一する。
